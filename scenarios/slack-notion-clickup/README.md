# Slack, Notion, and ClickUp

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Turn a Slack or form event into an ops task.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [Bug report webhook to a ClickUp task](bug-report-to-clickup/) | intermediate | Create a ClickUp bug from a form and log the reporter. |
| [ClickUp status webhook to Slack](clickup-status-to-slack/) | beginner | Log a ClickUp status change and post it. |
| [Meeting notes webhook to ClickUp tasks](meeting-notes-to-clickup/) | intermediate | Create one ClickUp task from a meeting-note webhook and log it. |
| [Notion comment webhook to Slack](notion-comment-webhook-to-slack/) | beginner | Log a Notion comment notification and post the page title. |
| [Slack shortcut to a Notion page and a ClickUp task](slack-notion-clickup/) | intermediate | Turn a Slack shortcut payload into a cleaned task, then create both a Notion page and a ClickUp task. |
| [Standup sheet rows into Slack](standup-rows-to-slack/) | beginner | Post each standup row flagged YES, one message per person. |
| [Webhook a decision into a logged note](sheet-row-to-notion-proxy/) | beginner | Log a decision webhook. The HTTP step is the slot for a Notion call you connect. |
