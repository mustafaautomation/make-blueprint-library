# E-commerce

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Sync orders, refunds, and stock signals out of a store.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [Abandoned checkout text](abandoned-checkout-text/) | intermediate | Text a shopper who left a checkout only when an email and a phone are both present. |
| [Low-stock rows to Slack](low-stock-slack/) | beginner | Post one Slack message per sheet row whose reorder flag is YES. |
| [Negative review webhook to Slack](review-sentiment-slack/) | intermediate | Log a product review and ping Slack when the model calls it negative. |
| [Order line items into a sheet](line-items-to-sheet/) | intermediate | Split an order's line-item array into one sheet row each. |
| [Product blurb to a description cell](product-blurb-to-description/) | beginner | Turn a product blurb in column A into a description in column B. |
| [Shopify order sync to Sheets, Slack, and HubSpot](shopify-order-sync/) | intermediate | Log a Shopify order webhook, tell Slack, and create a HubSpot contact when the order is paid. |
| [Shopify refund webhook to Slack](shopify-refund-alert/) | beginner | Log a refund payload and ping Slack when the amount is at least 100. |
| [Supplier delay email to the warehouse channel](supplier-delay-email/) | beginner | Read a supplier delay email and post the new date when one is present. |
| [VIP order amount to Slack](vip-order-slack/) | beginner | Ping Slack when an order total scores at or above 500. |
| [WooCommerce order sync to Sheets and an order note](woocommerce-order-sync/) | intermediate | Log a WooCommerce order webhook and write an order note back through the REST API. |
| [WooCommerce refund note back to the order](woo-refund-note/) | intermediate | Log a Woo refund webhook and write an internal order note. |
