# HR and recruiting

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Parse applications and score them against a rubric.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [Draft a rejection from the stage in the subject](rejection-stage-draft/) | advanced | Draft a short, neutral rejection. Do not send it. Do not include the score. |
| [Draft an application acknowledgement](application-ack-draft/) | beginner | Draft a neutral acknowledgement for an application email. Do not send it. |
| [Employee referral to the hiring channel](referral-candidate-slack/) | beginner | Log a referral and ping Slack when an email address is present. |
| [Interview invite drafts from a sheet](interview-invite-drafts/) | intermediate | Draft an interview invite for each row flagged YES. Nothing is sent. |
| [Interview notes to a scorecard cell](interview-notes-scorecard/) | intermediate | When interview notes land in column A, write a scorecard into column B. |
| [Offer details logged for a human draft](offer-details-draft-slot/) | intermediate | Log offer details and post them. Do not email the candidate. |
| [Parse a CV email and score it against a rubric](hr-cv-parse-score/) | advanced | Read an application email, score it against a written rubric, and draft a reply. Nothing is sent automatically. |
