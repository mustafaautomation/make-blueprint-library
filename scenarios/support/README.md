# Support

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Classify a ticket and route it to the right queue.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [CSAT webhook logged to a sheet](csat-webhook-to-sheet/) | beginner | Log a CSAT score and ping Slack when it is 2 or lower. |
| [Product changelog RSS to Slack](changelog-rss-to-slack/) | beginner | Tell support, in two sentences, what a changelog entry actually changed. |
| [Refund language in a ticket pings finance](refund-request-to-finance/) | intermediate | Read a support webhook and ping finance only when the customer asked for money back. |
| [Split a ticket into bug or billing](bug-or-billing-router/) | intermediate | Label a ticket as bug or billing and post it to the matching Slack sentence. |
| [Status page change to Slack](status-page-to-slack/) | beginner | Log a status-page webhook and post the incident title. |
| [Support note to a macro draft](support-macro-from-note/) | intermediate | Turn a pasted ticket note into a reusable macro in the next column. |
| [Support ticket classification and routing](support-ticket-classify-route/) | intermediate | Classify a ticket webhook as urgent or normal, update Zendesk, and page Slack only for urgent ones. |
| [Ticket from a VIP domain pings Slack](vip-domain-ticket/) | intermediate | Ping Slack when the ticket email domain is on the VIP list in the prompt. |
