# Reporting

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Roll a sheet or API up into a Slack or email digest.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [Ad spend rows with a plain-language note](ad-spend-anomaly-note/) | intermediate | Read ad rows marked YES and describe only the changes the sheet already shows. |
| [Daily sales rows to a Slack note](daily-sales-digest/) | beginner | Join the rows marked Send and write a daily sales note. |
| [Hiring funnel counts to a short note](hiring-funnel-note/) | beginner | Turn stage counts into a note for the hiring channel and an email. |
| [Inventory value lines emailed to ops](inventory-value-email/) | beginner | Email a short inventory note from the rows marked YES. |
| [Month-end checklist status to Slack](month-end-checklist-note/) | beginner | Summarize which close tasks are still open. |
| [Pipeline snapshot rows to a Monday note](pipeline-snapshot-note/) | beginner | Describe the pipeline rows marked YES. No forecast. |
| [Support volume narrative](support-volume-narrative/) | beginner | Turn a week of ticket counts into a short note for Slack and email. |
| [Weekly KPI narrative to Slack and email](weekly-kpi-slack-email/) | intermediate | On a schedule, join the KPI rows, ask for a short narrative, and send it to Slack and the leadership list. |
