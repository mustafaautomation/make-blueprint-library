# Speed to lead

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Reply by SMS or email while the inquiry is still warm.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [After-hours form pages only the owner](after-hours-owner-only/) | beginner | Text the owner when the form says after_hours, and only log it during the day. |
| [Callback request with a named time](callback-request-score/) | intermediate | Ping Slack when a callback form names a time. Log the ones that do not. |
| [Demo request becomes a follow-up draft](demo-request-draft/) | intermediate | Draft a demo follow-up when the request names a tool and a date. Leave a quiet note otherwise. |
| [Missed-call text-back](missed-call-text-back/) | beginner | When a call payload is marked missed, text the caller and log the number so the team can ring back. |
| [Quote request texts the owner](quote-request-text-owner/) | beginner | Score a quote request and text the owner when the budget is named. |
| [Speed-to-lead SMS and email](speed-to-lead-sms-email/) | beginner | Text and email a new lead in the same run, and text the on-call owner when the form says it is after hours. |
| [Trial signup SMS and a quiet log](trial-signup-speed-to-lead/) | beginner | Text a new trial user when the model thinks the company is real. |
