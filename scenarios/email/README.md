# Email

Portfolio demos by Mustafa ([mustafaautomation](https://github.com/mustafaautomation)). Not client work.

Triage a mailbox, draft replies, and file what matters.

| Scenario | Difficulty | Description |
| --- | --- | --- |
| [AI email triage and draft replies](ai-email-triage-drafts/) | intermediate | Classify a new Gmail message and leave a draft reply for sales, billing, or support instead of sending it. |
| [Classify a cold-email reply](cold-reply-classifier/) | intermediate | Label a reply as interested, not now, or unsubscribe, and ping Slack only for interested. |
| [Draft an acknowledgement for a new client email](new-client-ack-draft/) | beginner | Log a new-client email and draft a short acknowledgement. Nothing is sent. |
| [Flag legal keywords in the shared inbox](legal-keyword-mail-to-slack/) | beginner | Log inbound mail and ping Slack when the model sees a contract, lawsuit, or subpoena. |
| [Intro request summarized for a double opt-in](intro-request-draft-note/) | intermediate | Summarize an intro request so you can ask the other person before forwarding. |
| [Log out-of-office replies and stay quiet](out-of-office-skip-log/) | beginner | Log auto-replies and ping Slack only when the message is not an out-of-office. |
| [Parse an order confirmation email into a sheet](order-email-to-sheet/) | beginner | Turn a supplier order confirmation into order number, total, and ETA. |
| [Separate a newsletter reply from a lead](newsletter-reply-not-a-lead/) | intermediate | Ping Slack only when a reply asks to buy, not when it says unsubscribe. |
